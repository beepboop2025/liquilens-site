What OK means

The API health endpoint reports liveness: the service is up and answering. Data freshness is reported inside each data payload with its own as of stamp, because freshness is a property of each feed, not of the process. When a feed goes dark, the payload that depends on it says so instead of serving a stale number as current.

ANSWERED is weaker than OK, and the demo row earns only that. demo.liquilens.in sits behind an access request and sends no cross origin headers, so your browser can see that the host replied and cannot read what it replied. A 401 and a 500 look identical from here, and calling either one OK would be dressing absence up as calm.
