Install

A strict verifier with no runtime dependency.

python -m pip install https://github.com/beepboop2025/liquilens-evidence-carrier/releases/download/v0.14.0/liquilens_evidence-0.14.0-py3-none-any.whl
liquilens-evidence issue descriptor.json > carrier.json
liquilens-evidence verify carrier.json --as-of 2026-08-24T12:00:00Z
liquilens-evidence convert carrier.json --format fdc3

The wheel is served from the signed v0.14.0 release with SHA-256 f0162affab57…df860cd24. The release also contains a checksum-pinned MCPB bundle and an offline, read-only liquilens-evidence-mcp server for current and initialization-based MCP clients. The repository includes a reusable GitHub Action, pre-commit hook, cross-language Node.js hash verifier and dependency-free dbt test.

Fail closed

Transport never upgrades authority.

Full

Licensed or allowed, redistributable, attributed and unexpired evidence may retain its payload.

Metadata only

Expired or incompletely licensed evidence keeps identity and provenance while omitting the payload.

Reject

Restricted, unknown or blocked rights stop export entirely—even when the destination accepts the bytes.
