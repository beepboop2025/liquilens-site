Install

A strict verifier with no runtime dependency.

Open the no-install verifier to validate a local carrier entirely inside your browser; it sends no document data over the network. Or run the hash-pinned release without keeping a Python environment:

uvx --no-cache --from 'https://github.com/beepboop2025/liquilens-evidence-carrier/releases/download/v0.16.0/liquilens_evidence-0.16.0-py3-none-any.whl#sha256=317c06b728a2b087eca3d51ba1cdf3f7570e4078334829959008ceb0a29dfd11' liquilens-evidence --help

python -m pip install https://github.com/beepboop2025/liquilens-evidence-carrier/releases/download/v0.16.0/liquilens_evidence-0.16.0-py3-none-any.whl
liquilens-evidence issue descriptor.json > carrier.json
liquilens-evidence verify carrier.json --as-of 2026-08-24T12:00:00Z
liquilens-evidence convert carrier.json --format fdc3

The wheel is served from the signed v0.16.0 release with SHA-256 317c06b7…29dfd11. This release keeps the rights-aware four-product Fleet Brief intact while binding source, wheel, MCPB, Registry card and opt-in plugin discovery to one release identity. It also contains a checksum-pinned MCPB bundle and an offline, read-only liquilens-evidence-mcp server for current and initialization-based MCP clients.

Fail closed

Transport never upgrades authority.

Full

Licensed or allowed, redistributable, attributed and unexpired evidence may retain its payload.

Metadata only

Expired or incompletely licensed evidence keeps identity and provenance while omitting the payload.

Reject

Restricted, unknown or blocked rights stop export entirely—even when the destination accepts the bytes.
