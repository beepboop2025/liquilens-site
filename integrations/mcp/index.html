Safe client sequence

Discover

Initialize the server and list tools at runtime. Compare the returned server version with the catalog before relying on a release claim.

Call

Send bounded topic or institution arguments. Preserve the tool's source fields and status rather than summarising them away.

Refuse

If evidence is unavailable, partial, structurally limited or not evaluated, do not convert the response into a healthy conclusion.

Authority boundary

The MCP annotations are read-only and non-destructive. They do not make the response investment advice, a rating, an order, a complete dataset or a verified Evidence Carrier.

Questions from integrators

Which MCP endpoint should an agent use?

Use api.liquilens.in/mcp for LiquiLens institution-risk tools and liquilens.in/mcp/financial-evidence for fixed routing across the four evidence products.

Are the MCP tools allowed to trade or make credit decisions?

No. The public tools are read-only and grant no execution, recommendation, credit-rating or financial authority.
