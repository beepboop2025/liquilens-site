01 / Indian bank research

What changed in the bank's NPAs?

First list covered banks. Then use an exact slug, such as cosmos-ucb, to fetch its accepted filing and disclosed history. The script checks coverage before requesting a review.

python3 financial_research.py bank-review python3 financial_research.py bank-review --slug cosmos-ucb

Read evidence.review.period_end, available_at, npa_movement, sources and interpretation_limits together. Write-offs remain separate from cash recoveries.

02 / US dollar funding

What does the funding desk actually show?

Fetch Seiche's complete money-market context: overnight rates, funding channels, source dates, methodology and caveats. This reads the completed desk; it does not start data collection.

python3 financial_research.py funding-brief

Read evidence.money_market.asof, freshness, sections, source_metadata and caveats. An unavailable desk remains unavailable; older observations keep their clocks.

Keep the result: append > research.json to save the returned JSON. Exit code 0 means evidence was returned, including any stale or historical facts; 2 means the requested review is unavailable or not covered; 1 means a request or tool failed. Read the evidence state before drawing a conclusion.

How the recipes connect and identify test traffic

The file uses Python's standard library and MCP 2025-11-25 initialization. Only the two documented HTTPS endpoints are allowed. Each HTTP exchange has a 20-second deadline and a 2 MiB response limit; there are no automatic retries or scheduled calls. Its MCP client name is liquilens-research-recipes, version 1.0.0. This identifies the example, not a person or unique installation.

Operators testing the recipe should add --verification. That marks requests as synthetic verification so rehearsal calls can be excluded from adoption counts. Ordinary readers should use the commands above. Recipe manifest.
