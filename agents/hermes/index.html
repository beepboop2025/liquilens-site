Connect Hermes

  1. Add the research servers

    Download hermes.yaml, or copy the configuration below. Merge its mcp_servers entries into ~/.hermes/config.yaml, preserving your other settings and servers. Review the three endpoint URLs before saving.

    View the complete configuration
    mcp_servers:
  seiche:
    url: https://api.seiche.info/mcp
    tools:
      include: ["data_health", "funding_stress_now", "money_market_context"]
  liquilens:
    url: https://api.liquilens.in/mcp
    tools:
      include: ["banking_specialisation_coverage", "bank_asset_quality_review", "institution_review_packet", "universe_search"]
  undertow:
    url: https://api.seiche.info/undertow/mcp
    tools:
      include: ["exit_cost", "venue_concentration"]

  2. Check discovery

    hermes mcp test seiche
hermes mcp test liquilens
hermes mcp test undertow

    Look for successful connections to all three servers. This configuration selects nine research tools; Hermes may also register resource and prompt helpers.

  3. Run your first research task

    Start a new Hermes chat or use /reload-mcp in an existing session. Ask it to use the connected research tools with the task below.

Start with a question that needs evidence

Use the connected financial research tools to prepare a research brief. Start with Seiche money_market_context and data_health. Show funding conditions, observation dates, units and stale or missing sources. Use Undertow exit_cost for a $100,000 BTC exit estimate and keep each venue separate. If I name a bank, resolve its exact LiquiLens coverage before reviewing its filings. Return evidence, sources and open questions.

For a first look without configuring an agent, run the funding question in your browser. The result includes source quality and export options.

If a connection needs attention

If a server connects but a tool is missing, check its tools.include list and reload MCP. If a connection fails, run hermes mcp test SERVER_NAME for that server and inspect the reported HTTP error.

If your client does not recognise an mcp command, check its version and official instructions. If a source is unavailable or stale, retain that state in the brief and continue with any available evidence.

Use the evidence with its limits

These tools supply public research. They do not execute orders or certify a bank’s safety. Check the source dates and coverage before drawing a conclusion.
