One useful workflow, ready for your scheduler

Unzip the kit. Python 3.11 or newer is enough; there are no packages or model keys to install.

  1. Check the connection

    python3 trading_brief.py doctor

    Checks the three MCP connections and required tools. It does not run research or modify your agent.

  2. Make your first brief

    python3 trading_brief.py run --size-usd 100000 > first.json

    Reads funding context and published BTC exit estimates. Add --slug cosmos-ucb for the covered bank example. Choose a covered institution.

  3. Come back to the evidence

    python3 trading_brief.py run --size-usd 100000 --previous first.json > next.json

    Compares the same request with the saved brief. Source clocks and revisions count as payload changes; the result does not claim a trading signal. Use --format markdown for a readable export.

The script runs once and exits. Schedule it at the cadence your research needs. A partial result exits with code 2 and retains the available sections; transport failure never becomes a neutral market reading.

Know what the result means

These tools supply public research evidence. They do not execute orders, recommend a venue, certify deposit safety or assess a private book's compliance. Dates, stale sources, unavailable data and access restrictions stay in the response. The free kit requires no subscription; private services retain their own access rules.

Nothing runs when this page loads. The kit writes only to standard output unless you redirect it. It creates no persistent identifier. Operator tests use --verification and are excluded from adoption reporting.
