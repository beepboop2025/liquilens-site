Connect OpenClaw

  1. Add the research servers

    Download openclaw.json, or copy the configuration below. Merge its mcp.servers entries into ~/.openclaw/openclaw.json, preserving your other settings and servers. Review the three endpoint URLs before saving.

    View the complete configuration
    {
  "mcp": {
    "servers": {
      "seiche": {
        "url": "https://api.seiche.info/mcp",
        "transport": "streamable-http",
        "toolFilter": {
          "include": [
            "data_health",
            "funding_stress_now",
            "money_market_context"
          ]
        }
      },
      "liquilens": {
        "url": "https://api.liquilens.in/mcp",
        "transport": "streamable-http",
        "toolFilter": {
          "include": [
            "banking_specialisation_coverage",
            "bank_asset_quality_review",
            "institution_review_packet",
            "universe_search"
          ]
        }
      },
      "undertow": {
        "url": "https://api.seiche.info/undertow/mcp",
        "transport": "streamable-http",
        "toolFilter": {
          "include": [
            "exit_cost",
            "venue_concentration"
          ]
        }
      }
    }
  }
}

  2. Check discovery

    openclaw mcp probe --json

    Check that Seiche, LiquiLens and Undertow are available, with three, four and two selected research tools respectively. Inspect any diagnostics before starting your research task.

  3. Run your first research task

    Once discovery succeeds, use the research task below in an OpenClaw agent session whose runtime supports the saved MCP servers. Follow your installed release’s MCP runtime instructions.

Start with a question that needs evidence

Use the connected financial research tools to prepare a research brief. Start with Seiche money_market_context and data_health. Show funding conditions, observation dates, units and stale or missing sources. Use Undertow exit_cost for a $100,000 BTC exit estimate and keep each venue separate. If I name a bank, resolve its exact LiquiLens coverage before reviewing its filings. Return evidence, sources and open questions.

For a first look without configuring an agent, run the funding question in your browser. The result includes source quality and export options.

If a connection needs attention

If discovery succeeds but the tools do not reach your session, check which runtime is consuming the saved MCP registry. openclaw mcp status --verbose inspects saved settings; openclaw mcp probe --json checks live discovery. The separate mcporter registry uses its own configuration.

If your client does not recognise an mcp command, check its version and official instructions. If a source is unavailable or stale, retain that state in the brief and continue with any available evidence.

Use the evidence with its limits

These tools supply public research. They do not execute orders or certify a bank’s safety. Check the source dates and coverage before drawing a conclusion.

This page makes no research calls on load. Explicit configuration copies, download requests and prompt copies are counted in aggregate without visitor identifiers. Operator verification is excluded; setup actions do not establish installations or users.
